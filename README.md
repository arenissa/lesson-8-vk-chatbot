# VK Chat-Bot Зерокодер (ProxyAPI + VK API)

Чат-бот для сообщества ВКонтакте, который консультирует клиентов по курсам онлайн-университета Зерокодер (zerocoder.ru).

## Требования

- Python 3.8+
- Токен ProxyAPI (proxyapi.ru) — даёт доступ к OpenAI, Anthropic, Gemini через прокси
- Токен сообщества ВКонтакте (с правами на сообщения)

## Установка

### 1. Получение ключей

**ProxyAPI:**
1. Зарегистрируйтесь на https://proxyapi.ru
2. Перейдите в личный кабинет → раздел API ключ
3. Скопируйте токен
4. Пополните баланс (для OpenAI gpt-4o-mini ~0.72 ₽ / 1000 токенов входа)

**VK API:**
1. Откройте управление сообществом
2. Перейдите: Управление → Дополнительно → Работа с API
3. Включите Long Poll API
4. Скопируйте «Ключ доступа»

### 2. Настройка переменных окружения

Скопируйте файл `.env.example` в `.env` и заполните своими ключами:

```bash
cp .env.example .env
```

Содержимое `.env`:

```
PROXY_API_KEY=ваш_токен_proxyapi
OPENAI_MODEL=gpt-4o-mini
VK_TOKEN=ключ_сообщества_vk
VK_GROUP_ID=id_сообщества
```

> **ВАЖНО:** Никогда не коммитьте файл `.env` в репозиторий!

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск бота

```bash
python bot.py
```

## Как это работает

1. Бот слушает входящие сообщения через VK Long Poll API
2. При получении сообщения отправляет его в OpenAI API через ProxyAPI (https://api.proxyapi.ru/openai/v1)
3. GPT генерирует ответ на основе базы знаний о курсах Зерокодер
4. Бот отправляет ответ обратно в VK

## Модели OpenAI (через ProxyAPI)

| Модель | Описание | Цена (~₽/1K токенов) |
|--------|----------|----------------------|
| gpt-4o-mini | Быстрая и дешёвая | ~0.72 вход / ~2.88 выход |
| gpt-4o | Мощная, мультимодальная | ~18 вход / ~72 выход |
| gpt-4-turbo | Быстрая версия GPT-4 | ~30 вход / ~60 выход |

## Технологии

- **openai** — клиент OpenAI SDK через ProxyAPI прокси
- **vk_api** — работа с API ВКонтакте
- **python-dotenv** — загрузка переменных окружения
